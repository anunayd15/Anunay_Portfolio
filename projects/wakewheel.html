WakeWheel

★ Best Overall Project
OVERVIEW

WakeWheel was developed as a steering-wheel-mounted driver-safety system capable of monitoring heart-rate data while a vehicle is being operated.

The system was designed around the idea that changes in a driver's heart rate could provide an additional indicator of increasing drowsiness. When the measured signal crossed defined thresholds, the embedded system could trigger a physical alert for the driver while transmitting event data to a connected dashboard.

HOW IT WORKS

01

Sense

A heartbeat sensor embedded into the steering-wheel sleeve measures the driver's pulse through hand contact.

→

02

Process

An ESP32-C3 microcontroller processes incoming sensor data and evaluates it against the programmed heart-rate logic.

→

03

Alert

When a concerning condition is detected, the system provides haptic feedback through the steering-wheel sleeve to regain the driver's attention.

→

04

Record

Sensor and event information can be transmitted through Firebase to a dashboard for monitoring and analysis.

HARDWARE

ESP32-C3 Microcontroller

The ESP32-C3 served as the embedded controller, processing sensor readings and supporting communication between the physical device and the connected software system.

Heart-Rate Sensing

A heartbeat sensor collected physiological data through contact with the driver's hand on the steering wheel.

Haptic Feedback

The sleeve incorporated vibration feedback so an alert could be delivered physically without requiring the driver to look away from the road.

RECOGNITION

Best Overall Project

WakeWheel was awarded Best Overall Project by Texas Convergent when it was presented during the final demo day.

In the end, a successful IoT prototype was developed that integrated heart-rate sensing, embedded control, physical feedback, wireless data communication, and a connected dashboard into a single system. WakeWheel demonstrated how a compact embedded device could connect a physical driver-safety system with a cloud-based monitoring interface, while bringing together hardware, embedded programming, sensor processing, and front-end visualization.
